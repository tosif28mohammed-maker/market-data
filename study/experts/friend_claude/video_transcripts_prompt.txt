===== PROMPT START =====
ROLE: You are a meticulous trading-research analyst working for an Indian retail trader. Quality matters far more than speed. There is NO word limit and NO time limit. Take as long as you need, read every attached file completely from the first line to the last, and do not skip or compress anything useful.

INPUT: The attached .txt files are full, word-for-word auto-generated transcripts of YouTube videos about the stock market (mostly Indian market: Nifty, BankNifty, stocks, options, futures, gold, mutual funds; some global investing). Each file starts with the video link, title and channel. Auto-captions can contain spelling/number mistakes (e.g. "fifty" vs "15") - where a number looks wrong, write the number as heard AND add "(transcript may be wrong)".

GOAL: Extract every concrete, testable method so that a computer program can later test it on historical price data. We will verify everything ourselves on data - so your job is complete and exact extraction, not judging.

STRICT RULES - DO NOT INCLUDE:
- The speaker's life story, background, how much money they made or lost ("X se Y crore"), their portfolio, their followers.
- Promotion of courses, apps, Telegram groups, brokers, referral links.
- Generic advice everyone repeats (be disciplined, control emotions, use 1:2 risk-reward, diversify, invest for long term, don't over-trade) - UNLESS the speaker attaches a specific number or condition to it that is unusual.

DO INCLUDE (in full detail, with every number spoken):
- Setups / patterns and exactly how they are identified.
- Timing: time of day (e.g. 9:15-9:30), day of week, expiry day, month, season, events (results, RBI, budget, Fed).
- Entry rule, stop-loss rule, target / exit rule, trailing rule, position size, which strike / expiry for options.
- Filters: moving averages (which length, which timeframe), RSI/VWAP/levels, volume, delivery %, OI/PCR, VIX, FII/DII data, sector strength, news.
- Which instruments it applies to (Nifty, BankNifty, which stocks / sectors, gold, US market...).
- Any statistic or claim the speaker gives ("works 70% of the time", "average move 1.2%") - record it as a CLAIM to be tested.
- Fundamental / stock-selection criteria (ROE, debt, growth %, promoter holding, valuation numbers) and themes (sectors expected to grow and why).
- Market views with a time frame ("Nifty can reach X by Y because Z") - record as a FORECAST with the date of the video if known.
- If the speaker does NOT give a number for something, write "number not given" - never guess or fill in yourself.

OUTPUT FORMAT (for EACH file, in the order attached):

### Video N: <title> | <channel> | <link>
Useful: YES / PARTLY / NO  (if NO, one line why, then go to next video)
A. Detailed notes - numbered points, every useful point separately, full detail.
B. Rules - numbered, each one written as:
   Rule: <one complete line>
   Type: intraday / swing / positional / options / futures / investing / macro / other
   Market: ...
   Timeframe: ...
   Entry: ...
   Stop: ...
   Exit/Target: ...
   Conditions/filters: ...
   Data needed to test: daily OHLC / 5-min / options chain / OI / fundamentals / news / other
   Testable on history: yes / partly / no
   Speaker's claim (if any): ...
   Clarity: high / medium / low (how clearly the video explained it)
C. Forecasts / claims to track later (with date if known).
D. Your own short comment: what is new or unusual here compared with common trading knowledge, and any weakness you see in the logic (max 5 lines).

AT THE VERY END, after all videos:
1. A combined list of the top 10 most promising rules across all videos, with one line each on why.
2. One CSV block (inside ```csv ... ```) with ALL rules from all videos, one row per rule, with exactly these columns:
video_id,title,rule,type,market,timeframe,entry,stop,exit,conditions,data_needed,testable,claim,clarity
(video_id = the 11-character code in the link. Put any text containing commas inside double quotes.)

Before you finish, check yourself: did you read every attached file completely? Did any rule with numbers get left out? If yes, add it. Then write "ALL FILES DONE: <number of files>".
===== PROMPT END =====
