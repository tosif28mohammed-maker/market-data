# market-data
Daily end-of-day prices (Nifty, India VIX, Nifty-50 stocks) fetched automatically by GitHub Actions at 5:00 PM IST, Monday-Friday.
`data/<SYMBOL>.csv` = full history; `data/latest.csv` = latest day for all; `data/STATUS.txt` = last update.
Used by Claude for the daily market study. Source: Yahoo Finance (via yfinance). Not investment advice.
